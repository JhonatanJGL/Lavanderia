# Como colocar este proyecto en el repositorio del grupo

1. Descomprima `Lavanderia_Entrega_Final.zip`.
2. Abra GitHub Desktop y confirme que la rama actual sea `matias-borja`.
3. Use **Repository > Show in Explorer** para abrir la carpeta clonada del repositorio.
4. Haga una copia de seguridad de la carpeta actual.
5. Copie el contenido de `Lavanderia_Entrega_Final` dentro de la carpeta clonada y reemplace los archivos antiguos.
6. Abra esa carpeta desde IntelliJ mediante **File > Open** y seleccione `pom.xml` como proyecto Maven.
7. Ejecute `Poo_lavanderia.sql` en MySQL Workbench.
8. Revise las credenciales de `Conexion.java`.
9. Recargue Maven y ejecute `com.example.lavanderia.app.Main`.
10. Pruebe todo antes de realizar el commit y el push.

No copie las carpetas `target`, `out` ni archivos temporales de IntelliJ.
